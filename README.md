# Python Voice Assistant

A simple Python-based voice assistant that uses **Google Text-to-Speech (gTTS)** for converting text to speech and plays the generated audio using the **playsound** module. This project can serve as a foundation for building more advanced voice-based applications.

---

## Features
- Converts text into speech using the **gTTS** library.
- Plays the generated speech audio using the **playsound** module.
- Extensible to include speech recognition for voice commands.

---

## Requirements
- Python 3.6 or higher
- The following Python packages:
  - `playsound`
  - `gTTS`
